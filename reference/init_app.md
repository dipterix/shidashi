# Initialize a shidashi application

Creates a fresh environment holding all per-application global stores
(session registry, per-module input registries, etc.). This function is
designed to be called from a `global.R` file generated by
[`render()`](https://dipterix.org/shidashi/reference/render.md), not for
user's call.

## Usage

``` r
init_app(env = parent.frame())
```

## Arguments

- env:

  environment where the application is initialized into.

## Value

Nothing.

## Examples

``` r

init_app(env = new.env())
```
